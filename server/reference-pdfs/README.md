# Reference PDF Templates

This folder contains the reference PDF templates for seating plan formats.

## Files to Place Here

Please copy your 4 PDF template files to this folder:

1. **main-gate-format.pdf** (or notice-board-format.pdf)
   - Format for display at main gate and notice boards
   - Master format from which others are derived

2. **room-folder-slip-format.pdf**
   - Format for room supervisor folders
   - One slip per room

3. **room-door-slip-format.pdf**
   - Format for display on examination room doors
   - One slip per room

4. **cbse-copy-format.pdf**
   - Format for CBSE submission
   - Official copy format

## Purpose

These PDFs serve as reference templates. The system will:
1. Analyze each PDF format
2. Extract specifications (margins, fonts, layout)
3. Create matching HTML templates
4. Generate output PDFs that exactly match these formats

## File Naming Convention

Use clear, descriptive names:
- `main-gate-format.pdf`
- `room-folder-slip-format.pdf`
- `room-door-slip-format.pdf`
- `cbse-copy-format.pdf`

## Next Steps

After placing PDFs here:
1. System will analyze each format
2. Document specifications
3. Create HTML templates in `server/src/templates/`
4. Build PDF generation system
